How I work

Start from the outcome

Every epic gets a clear value statement and a measurable KPI before it enters the backlog.

Prioritize in the open

I use RICE and MoSCoW so stakeholders can see why one item ranks above another.

Write stories teams can build

User stories with acceptance criteria and a shared Definition of Ready and Done.

Keep releases predictable

I manage scope, dependencies, and risks, and I run UAT before go-live.
